**Advanced Forecasting of Malaysia's Pharmaceutical Imports**

This project forms part of my Final Year Project for a Bachelor of Science in Actuarial Science at the National University of Malaysia (UKM).

**Objective:** To develop a robust time-series model (ARIMAX) to forecast Malaysia's pharmaceutical import trends and quantify the structural impact of external economic and policy events.

**Methodology:**
- Data sourced from international trade databases.
- Time-series modeling was performed using ARIMAX with intervention analysis in **R**.
- The model was used to isolate and measure the impact of specific events on import values.

**Key Skills Demonstrated:**
- Statistical Modeling and Forecasting
- Data Analysis with R
- Translating complex data into strategic insights
